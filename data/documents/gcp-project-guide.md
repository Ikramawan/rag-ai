# GCP Project Creation — Synthetic Training Guide

This fictional procedure is for testing the RAG application.
It is not an actual company policy.

## Prerequisites

- Obtain approval from the platform team.
- Confirm the target organisation and folder.
- Agree on a unique project ID.
- Identify the billing account and confirm permission to link it.

## Procedure

1. Create the project in the approved organisation and folder.
2. Link the project to the approved billing account before using paid services.
3. Apply the required labels: owner, environment and cost-centre.
4. Grant access using approved groups and least-privilege roles.
5. Enable only the APIs required for the workload.
6. Configure a budget and budget alerts.

## Important notes

- Budget alerts do not automatically stop spending.
- If billing permissions are missing, contact the billing administrator.
- This guide does not define networking or project deletion procedures.
